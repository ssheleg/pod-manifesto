# Security policy

## Supported surface

The current site and the current default branch are supported. Historical manifesto
tags are permanent citation records and do not receive site or tooling fixes.

## Reporting a vulnerability

Use [GitHub's private vulnerability report](https://github.com/ssheleg/pod-manifesto/security/advisories/new).
Do not disclose an exploitable issue in a public issue. Include the affected URL or
file, reproduction steps, impact, and any known mitigation.

The maintainer will acknowledge a report within seven days, validate the affected
surface, and keep the reporter informed until a fix or a documented rejection exists.
This is a static site with no accounts or payment data; content errors and broken
citations belong in the ordinary issue forms, not the security channel.
