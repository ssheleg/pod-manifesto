# Support and questions

Choose the repository that owns the question:

- A claim in the manifesto is wrong, stale, or too costly: open an
  [objection](https://github.com/ssheleg/pod-manifesto/issues/new?template=objection.yml).
- A translation exists or is planned: open a
  [translation request](https://github.com/ssheleg/pod-manifesto/issues/new?template=translation.yml).
- The site, a link, or a repository check is broken: open a
  [repository issue](https://github.com/ssheleg/pod-manifesto/issues/new/choose).
- Installation or behavior of the reference implementation: use
  [`sshlg-skills`](https://github.com/ssheleg/sshlg-skills/issues).
- A security vulnerability: follow [`SECURITY.md`](SECURITY.md) and report it privately.

This is a public manifesto repository, not a commercial support channel. There is no
guaranteed response time for ordinary questions.
